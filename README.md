## Features & Architecture Highlights

- **Typewriter Hero Section**: Interactive typewriter effect highlighting key technical engineering roles paired with a live, tabbed full-stack architecture story previewer.
- **Professional Work Experience**: Highlighted enterprise roles at SoftClans Technologies, Safaricom PLC, and the State Department for Tourism with company logos and key achievements.
- **Core Competencies & Stack**: Categorized technical proficiency (Cloud & DevOps, Software Engineering, Databases, Tools) rendered with vector SVG logos.
- **Verified Credly Badges**: Interactive modal & carousel displaying verified AWS, Terraform, Linux Foundation, and Google Cloud credentials with direct verification links.
- **Featured Projects**: Showcase of open-source challenges and high-throughput APIs with live GitHub repo links and documentation.
- **Dynamic Light & Dark Mode**: Glassmorphic theme switcher supporting automatic system theme preferences.
- **Privacy & Anti-Spam Protected**: Contact form powered by Formspree with sanitized input handling and zero raw phone number exposure to protect against scrapers.

## Local Development Setup

### Prerequisites
- Node.js `v18.x` or later
- npm `v9.x` or later

### Installation & Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/David-Kamau-Builds/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start local development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000/portfolio` in your browser.

4. **Build production export:**
   ```bash
   npm run build
   ```
